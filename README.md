# 📘 دوره جامع آموزش Git — از صفر تا حرفه‌ای
یک دوره‌ی جامع، عملی و فارسی برای یادگیری **Git** از مفاهیم پایه تا تکنیک‌های پیشرفته و کاربردی در پروژه‌های واقعی.

در این دوره، Git را فقط با حفظ کردن دستورات یاد نمی‌گیرید؛ بلکه با درک مفاهیمی مثل **Working Directory، Staging Area، Commit، Branch و Remote** یاد می‌گیرید که Git واقعاً چگونه کار می‌کند و چرا هر دستور را استفاده می‌کنیم.

## 🚀 در این دوره چه چیزهایی یاد می‌گیرید؟

از اولین `git init` شروع می‌کنیم و قدم‌به‌قدم به مباحث حرفه‌ای می‌رسیم:

- آشنایی کامل با Git و تفاوت آن با GitHub
- نصب و پیکربندی Git
- درک Working Directory، Staging Area و Repository
- کار با Commit، Log، Status و Diff
- مدیریت `.gitignore`
- Undo کردن تغییرات و کار با `reset` و `revert`
- ساخت و مدیریت Branchها
- Merge و حل Merge Conflict
- Rebase و Interactive Rebase
- کار با Remote Repositoryها
- GitHub، Push، Pull، Fetch و Clone
- Stash برای مدیریت تغییرات موقت
- Tag و مدیریت نسخه‌ها
- Cherry-pick
- Reflog و بازیابی اشتباهات
- Bisect برای پیدا کردن commitهای مشکل‌ساز
- Submodule
- Git Hooks
- آشنایی با معماری داخلی Git
- استانداردهای حرفه‌ای Commit Message
- Git Flow، GitHub Flow و Trunk-Based Development
- Pull Request و Code Review
- آشنایی مقدماتی با GitHub Actions و CI/CD
- دستورات و تکنیک‌های پیشرفته Git
- حل اشتباهات و سناریوهای رایج در پروژه‌های واقعی
- Cheat Sheet برای استفاده‌ی روزمره

## 🎯 هدف دوره

هدف این دوره این است که در پایان، بتوانید Git را **با اعتمادبه‌نفس در پروژه‌های شخصی، دانشگاهی و تیمی** استفاده کنید و هنگام مواجهه با مشکلاتی مثل Conflict، Rebase اشتباه، Commit اشتباه یا حذف شدن تغییرات، بدانید دقیقاً چه کاری باید انجام دهید.

این دوره برای کسانی طراحی شده که می‌خواهند:

> Git را از صفر شروع کنند و در نهایت به سطحی برسند که بتوانند در پروژه‌های واقعی و تیم‌های نرم‌افزاری از آن استفاده کنند.

## 📚 ساختار دوره

این آموزش در **۳۰ بخش** طراحی شده و مسیر یادگیری را از مفاهیم ابتدایی تا مباحث پیشرفته دنبال می‌کند.

**سطح:** مبتدی → متوسط → پیشرفته  
**موضوع:** Git و GitHub  
**زبان:** فارسی  
**نوع:** آموزش متنی و عملی

## 💻 مناسب برای چه کسانی است؟

- افرادی که تازه می‌خواهند Git را یاد بگیرند
- برنامه‌نویسان مبتدی و متوسط
- توسعه‌دهندگان وب و نرم‌افزار
- افرادی که می‌خواهند وارد کار تیمی شوند
- کسانی که Git را بلدند اما مفاهیم عمیق آن را نمی‌دانند
- کسانی که می‌خواهند Git و GitHub را به‌صورت اصولی یاد بگیرند

## 🛠️ روش پیشنهادی یادگیری

بهترین روش این است که دستورات را فقط نخوانید؛ **همزمان با دوره آن‌ها را در یک Repository واقعی اجرا کنید.**

اشتباه کنید، Conflict بسازید، Commit را برگردانید، Branchها را ادغام کنید و حتی عمداً Git را به هم بریزید و با ابزارهایی مثل `reflog` نجاتش دهید!

چون بهترین راه یادگیری Git این است که با آن **کار کنید، نه اینکه فقط درباره‌اش بخوانید.**
